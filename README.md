<h1 align="center">Kalkulator IPAL SPPG</h1>

<p align="center">Kalkulator kapasitas IPAL dapur SPPG teknologi MBBR, sesuai Kepmen LHK/Kepala BPLH No. 2760 Tahun 2025.<br>
Dikembangkan oleh Bidang Penataan dan Penaatan Lingkungan Hidup, DLH Kabupaten Cilacap.</p>

---

Halaman GitHub ini adalah **bingkai** yang membuka web app Google Apps Script. Kode aplikasi (Kode.gs dan file HTML `index`) ada di Apps Script, jadi setiap perubahan di Apps Script yang sudah di-deploy sebagai versi baru langsung tampil di sini.

## Isi repository

| File | Fungsi |
|---|---|
| `index.html` | Bingkai yang membuka web app Apps Script |
| `manifest.json` | Nama dan ikon agar bisa dipasang di HP |
| `sw.js` | Service worker untuk pemasangan di HP |
| `icon-*.png`, `apple-touch-icon.png`, `favicon.svg` | Ikon aplikasi |

## Memasang di HP

- **Android (Chrome):** buka alamat GitHub Pages, ketuk menu ⋮, lalu **Instal aplikasi** atau **Tambahkan ke layar utama**.
- **iPhone (Safari):** ketuk **Bagikan**, lalu **Tambahkan ke Layar Utama**.

Aplikasi membutuhkan koneksi internet karena isinya dimuat dari Apps Script.
